Topology Design

The "Edge Pool" Architecture

Because HermesPG compiles to a standalone 280 KB native binary with zero external runtime dependencies and uses only ~20 MB of RAM, it enables a distributed sidecar paradigm that traditional multi-megabyte proxies cannot match.

APPLICATION LAYER
10,000+ Clients

Kubernetes pods, serverless microservices, and short-lived lambdas firing concurrent queries without connection throttling.

HERMESPG SIDECAR
Transaction Multiplexing

Leases physical connections strictly for the duration of a transaction, returning them instantly in O(1) when Idle ('I').

Internal Mechanics

Core Engine Capabilities

Designed from first principles in Nim with deterministic memory safety and minimal syscall overhead.

SCRAM-SHA-256 Authentication

RFC 5802 & RFC 7677 SASL negotiation. Pure SHA-256 and PBKDF2-HMAC-SHA-256 cryptography with OS cryptographically secure random nonces (std/sysrand).

Monotonic Zero-Alloc Queue

Eliminates event-loop timer accumulation using monotonic deadlines (MonoTime) and an O(1) background watchdog. Guaranteed flat memory footprint under sustained multi-million transaction loads.

Multi-Core SO_REUSEPORT

Spawns autonomous asynchronous native worker threads bound to the same listener port via Linux kernel SO_REUSEPORT, scaling horizontally across all CPU cores with zero lock contention.

Direct Streaming Ingress

Ingests query frames in a single kernel receive syscall directly into a streaming buffer. Extended query pipeline batches (Parse, Bind, Execute, Sync) are parsed in 0 syscalls.

Fail-Fast Load Shedding

Bounded deque rejects surge traffic immediately (< 0.2ms) with SQLSTATE 53300, protecting PostgreSQL from cascading bufferbloat and lock starvation.

Session State Sanitization

Tracks session parameter mutations and automatically executes DISCARD ALL; before re-leasing dirty connections, ensuring strict transaction isolation.

Deployment

Quickstart

Run HermesPG as a standalone container or compile natively with Nim.

docker-compose.yml 
services:
  hermespg:
    image: ghcr.io/luisacosta828/hermespg:v0.2.0
    ports:
      - "6432:6432"
    environment:
      PGHOST: "postgres"
      PGPORT: "5432"
      PGUSER: "postgres"
      PGPASSWORD: "your_password"
      PGDATABASE: "postgres"
      HERMES_MAX_CONNS: "25"
      HERMES_WORKERS: "8"
    depends_on:
      - postgres

  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_PASSWORD: "your_password"
Connect your applications directly to port 6432: postgresql://postgres:your_password@localhost:6432/postgres
