Engineered for Performance

Under The Hood

Zero-cost abstractions, direct kernel syscalls, and strict adherence to the PostgreSQL v3 protocol.

🔐

SCRAM-SHA-256 Auth

Full RFC 5802 & RFC 7677 SASL negotiation. Pure SHA-256 and PBKDF2 cryptography with OS cryptographically secure random nonces.

⏱️

Zero-Alloc Wait Queue

Eliminates event-loop timer proliferation using high-resolution monotonic deadlines (MonoTime) and an O(1) single background watchdog.

🧵

Multi-Core SO_REUSEPORT

Scales horizontally across all CPU cores with native OS worker threads bound to the same port. Zero lock contention, linear scalability.

⚡

Direct Streaming Ingress

Reads packets directly from socket kernel buffers in a single syscall. Parses extended query pipeline batches in 0 syscalls.

🛡️

Fail-Fast Load Shedding

Bounded deque rejects traffic spikes instantly (< 0.2ms) with SQLSTATE 53300, shielding databases from cascading bufferbloat.

🧹

Automatic Sanitization

Tracks session parameter mutations and automatically executes DISCARD ALL; before leasing dirty connections back to clients.

Quickstart

Deploy HermesPG with Docker Compose or as a standalone native binary.

docker-compose.yml 
services:
  hermespg:
    image: ghcr.io/luisacosta828/hermespg:v0.2.0
    ports:
      - "6432:6432"
    environment:
      PGHOST: "postgres"
      PGPORT: "5432"
      PGUSER: "postgres"
      PGPASSWORD: "your_password"
      PGDATABASE: "postgres"
      HERMES_MAX_CONNS: "25"
      HERMES_WORKERS: "8"
    depends_on:
      - postgres

  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_PASSWORD: "your_password"
Ready to connect? Point your database connection string to port 6432:
postgresql://postgres:pass@localhost:6432/postgres
